Підрозділ 1.1

Створення напису (віджет Label) у tkinter

У бібліотеці tkinter для виведення текстової інформації у вікні програми використовують елемент керування (віджет) Label (напис).

Загальний синтаксис створення напису: ім'я = Label(вікно, властивість=значення, ...). Щоб напис з'явився у вікні, його розміщують за допомогою менеджера компонування: pack() або place(x=..., y=...).

from tkinter import *
root = Tk()
root.title("Написи в Python")
lbl = Label(root, text="Вітаю у 8 класі!")
lbl.pack() # розміщення напису у вікні
root.mainloop()

lbl.pack()Автоматичне пакування у вікні
lbl.place(x=40, y=60)Точне розміщення за координатами
Підрозділ 1.2

Оформлення напису: текст, кольори та шрифт

• text — рядок тексту, що відображається в написі;
• fg (або foreground) — колір символів тексту (наприклад, "blue", "white", "green");
• bg (або background) — колір фону під написом (наприклад, "yellow", "purple");
• font — кортеж із параметрами шрифту: ("Назва_шрифту", розмір, "накреслення"), де накреслення — "bold" (напівжирний), "italic" (курсив), "underline" (підкреслений);
• width та height — ширина (у символах) і висота (у рядках) текстового напису.
Підрозділ 1.3

Зміна властивостей напису під час роботи програми

Щоб оновити текст, колір або шрифт уже створеного напису під час виконання програми, використовують метод config() (або configure()).

Приклад зміни властивостей:
msg_lbl = Label(root, text="Очікування...")
msg_lbl.config(text="Роботу виконано!", fg="green")
